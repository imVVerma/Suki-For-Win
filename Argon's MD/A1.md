```markdown
# Project: Suki-Win (Windows Native Voice Workflow & Dictation Engine)

## Architecture Overview
A Windows port of the macOS `Suki` app built with **Tauri v2 (Rust)** and **React + Vite + Tailwind CSS**.
It operates two windows from a single process:
1. `main`: The Settings, Dictation History, and AI Insights Dashboard.
2. `hud`: A 220x48px frameless, transparent, always-on-top floating pill at the bottom of the screen.

## CRITICAL GUARDRAILS FOR AGENT (DO NOT VIOLATE)
1. **NO Subprocess Spawning (`std::process::Command` is BANNED):**
   - Never call external CLI tools like `ffmpeg.exe` or `sox.exe`. All audio capture must stay in-memory via Rust `cpal` and `hound` encoded directly into a `Cursor<Vec<u8>>` WAV buffer.
2. **Single-Instance Only:**
   - Do not remove `tauri_plugin_single_instance` in `src-tauri/src/main.rs`. This guarantees the `.exe` can never enter an infinite spawn loop.
3. **Strict `%APPDATA%` File I/O:**
   - Never write files, logs, or SQLite databases to relative paths (`./` or current working directory). Always resolve paths through `app.path().app_data_dir()`.
4. **Non-Activating HUD (`WS_EX_NOACTIVATE`):**
   - The `hud` window must NEVER steal focus from the user's active window (e.g., VS Code or browser) when shown. Always keep the Win32 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW` extended window style intact in `main.rs`.

## Next Tasks for Antigravity to Implement
- [ ] **Step 1:** Implement `src-tauri/src/groq.rs` using `reqwest` multipart upload to send the in-memory WAV buffer from `audio.rs` to `https://api.groq.com/openai/v1/audio/transcriptions` (`whisper-large-v3-turbo`), followed by a cleanup pass using `llama-3.3-70b-versatile`.
- [ ] **Step 2:** Capture the active foreground window title via `GetForegroundWindow` + `GetWindowTextW` before pasting so it is logged in SQLite (`active_app`) and passed to the LLM prompt for context-aware formatting.
- [ ] **Step 3:** Wire up the "Generate Daily Digest" button in `Dashboard.tsx` to query today's rows from `suki_history.db` and summarize key themes, action items, and WPM metrics.
```

### `src-tauri/src/main.rs`
Contains the **Single-Instance Lock** (preventing infinite `.exe` popups), the **Win32 Non-Activating HUD hook**, and the **Active Window Title reader**.

```rust
// Prevents an extra console window from popping up on Windows in release builds!
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

mod db;
use std::sync::Mutex;
use tauri::{Manager, WebviewWindow};

#[cfg(target_os = "windows")]
use windows::Win32::Foundation::HWND;
#[cfg(target_os = "windows")]
use windows::Win32::UI::WindowsAndMessaging::{
    GetForegroundWindow, GetWindowLongPtrW, GetWindowTextW, SetWindowLongPtrW,
    GWL_EXSTYLE, WS_EX_NOACTIVATE, WS_EX_TOOLWINDOW, WS_EX_TRANSPARENT,
};

/// Makes the Floating HUD never steal focus from VS Code / Browser when shown
#[cfg(target_os = "windows")]
fn make_window_non_activating(window: &WebviewWindow) {
    if let Ok(hwnd_raw) = window.hwnd() {
        let hwnd = HWND(hwnd_raw.0 as _);
        unsafe {
            let ex_style = GetWindowLongPtrW(hwnd, GWL_EXSTYLE);
            SetWindowLongPtrW(
                hwnd,
                GWL_EXSTYLE,
                ex_style | (WS_EX_NOACTIVATE.0 as isize) | (WS_EX_TOOLWINDOW.0 as isize),
            );
        }
    }
}

/// Reads the currently focused window title (e.g. "app.tsx - Visual Studio Code")
#[tauri::command]
fn get_active_window_context() -> String {
    #[cfg(target_os = "windows")]
    unsafe {
        let hwnd = GetForegroundWindow();
        let mut buf = [0u16; 512];
        let len = GetWindowTextW(hwnd, &mut buf);
        if len > 0 {
            return String::from_utf16_lossy(&buf[..len as usize]);
        }
    }
    "Unknown Window".to_string()
}

fn main() {
    tauri::Builder::default()
        // 1. BULLETPROOF GUARD: Prevents multiple .exe instances from ever spawning
        .plugin(tauri_plugin_single_instance::init(|app, _args, _cwd| {
            if let Some(main_win) = app.get_webview_window("main") {
                let _ = main_win.show();
                let _ = main_win.set_focus();
            }
        }))
        .setup(|app| {
            // 2. Initialize SQLite strictly inside %APPDATA%\com.suki.windows\
            let app_data_dir = app.path().app_data_dir().expect("Failed to resolve %APPDATA%");
            std::fs::create_dir_all(&app_data_dir)?;
            let db_path = app_data_dir.join("suki_history.db");
            let conn = db::init_db(&db_path).expect("Failed to initialize SQLite");
            app.manage(Mutex::new(conn));

            // 3. Apply Win32 non-activating styles to the HUD overlay
            if let Some(hud_window) = app.get_webview_window("hud") {
                #[cfg(target_os = "windows")]
                make_window_non_activating(&hud_window);
            }

            Ok(())
        })
        .invoke_handler(tauri::generate_handler![
            get_active_window_context,
            db::get_recent_dictations,
            db::insert_dictation
        ])
        .run(tauri::generate_context!())
        .expect("Error while running Suki-Win");
}
```

### `src-tauri/src/db.rs`
Uses bundled SQLite (`rusqlite`) so the database engine is statically compiled inside your `.exe` and stores everything safely inside `%APPDATA%`.

```rust
use rusqlite::{params, Connection, Result};
use serde::{Deserialize, Serialize};
use std::path::Path;
use std::sync::Mutex;
use tauri::State;

#[derive(Serialize, Deserialize, Clone)]
pub struct DictationEntry {
    pub id: i64,
    pub timestamp: String,
    pub raw_text: String,
    pub polished_text: String,
    pub active_app: String,
    pub duration_sec: f64,
    pub word_count: i64,
}

pub fn init_db(db_path: &Path) -> Result<Connection> {
    let conn = Connection::open(db_path)?;
    conn.execute(
        "CREATE TABLE IF NOT EXISTS dictations (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
            raw_text TEXT NOT NULL,
            polished_text TEXT NOT NULL,
            active_app TEXT NOT NULL,
            duration_sec REAL DEFAULT 0.0,
            word_count INTEGER DEFAULT 0
        )",
        [],
    )?;
    Ok(conn)
}

#[tauri::command]
pub fn insert_dictation(
    db: State<'_, Mutex<Connection>>,
    raw_text: String,
    polished_text: String,
    active_app: String,
    duration_sec: f64,
) -> Result<(), String> {
    let word_count = polished_text.split_whitespace().count() as i64;
    let conn = db.lock().map_err(|e| e.to_string())?;
    conn.execute(
        "INSERT INTO dictations (raw_text, polished_text, active_app, duration_sec, word_count)
         VALUES (?1, ?2, ?3, ?4, ?5)",
        params![raw_text, polished_text, active_app, duration_sec, word_count],
    )
    .map_err(|e| e.to_string())?;
    Ok(())
}

#[tauri::command]
pub fn get_recent_dictations(db: State<'_, Mutex<Connection>>) -> Result<Vec<DictationEntry>, String> {
    let conn = db.lock().map_err(|e| e.to_string())?;
    let mut stmt = conn
        .prepare("SELECT id, timestamp, raw_text, polished_text, active_app, duration_sec, word_count FROM dictations ORDER BY id DESC LIMIT 100")
        .map_err(|e| e.to_string())?;

    let rows = stmt
        .query_map([], |row| {
            Ok(DictationEntry {
                id: row.get(0)?,
                timestamp: row.get(1)?,
                raw_text: row.get(2)?,
                polished_text: row.get(3)?,
                active_app: row.get(4)?,
                duration_sec: row.get(5)?,
                word_count: row.get(6)?,
            })
        })
        .map_err(|e| e.to_string())?;

    let mut entries = Vec::new();
    for entry in rows.flatten() {
        entries.push(entry);
    }
    Ok(entries)
}
```

## 4. React Frontend Router (`src/main.tsx`)

Tauri v2 lets a single React bundle power both the **Dashboard** and the **Floating Pill** by checking `getCurrentWebviewWindow().label`.

```tsx
import React from "react";
import ReactDOM from "react-dom/client";
import { getCurrentWebviewWindow } from "@tauri-apps/api/webviewWindow";
import Dashboard from "./components/Dashboard";
import FloatingHud from "./components/FloatingHud";
import "./index.css";

const currentWindow = getCurrentWebviewWindow();
const isHud = currentWindow.label === "hud";

ReactDOM.createRoot(document.getElementById("root") as HTMLElement).render(
  <React.StrictMode>
    {isHud ? <FloatingHud /> : <Dashboard />}
  </React.StrictMode>
);
```

## 5. How to Compile for Both `x64` and `ARM64` Without Errors

When you are ready to build the `.exe` and `.msi`, you don't need any third-party wrappers:

```powershell
# 1. Build standard 64-bit Windows installer (Intel / AMD x64)
npm run tauri build -- --target x86_64-pc-windows-msvc

# 2. Cross-compile for Windows on ARM (Snapdragon X Elite / Surface ARM64)
rustup target add aarch64-pc-windows-msvc
npm run tauri build -- --target aarch64-pc-windows-msvc
```

Both commands output standalone installers inside `src-tauri/target/<arch>/release/bundle/nsis/` and `msi/`. Because `rusqlite` is set to `"bundled"` and audio stays in-memory, the binary has **zero external file lookups** that could fail on another user's laptop.
